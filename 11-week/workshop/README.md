# Taller semana 11 - Movie Rater

En este taller rediseño algunas pantallas de Movie Rater, la app de mi equipo, con lo que vimos en la semana 11.

- `app/`: copia del frontend de Movie Rater (Ionic React). El primer commit es la app tal como estaba, sin cambios.
- `docs/`: lo que voy haciendo en cada checkpoint.

## Para correr la app

    cd app
    npm install
    npm run dev

Necesita un archivo `app/.env` con `VITE_TMDB_API_KEY` y el backend de Movie Rater corriendo para el login y las reseñas.
